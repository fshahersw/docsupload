# Seeger Weiss agent specifications

Fourteen original task methods for the library: twelve specialized additions and two upgrades of existing adversarial-review and workstream-coordination roles. These are rich instructions and interface contracts, **not installed or deployed agents**.

`records.json` is a root array compatible with the current agent-skills catalog. Each record contains full original instructions, inputs, procedures, results, abstention cases, source provenance and integration candidates. Source tools remain disabled with `actual_binding:null`. A source-code declaration is not proof that a capability is configured or working on testing.seegerweiss.com.

## Contents

- `instructions/`: complete original firm-oriented task instructions; no model/personality scores or billing personas.
- `contracts/`: fourteen intake contracts and fourteen result contracts with evidence, coverage, source requests and review states.
- `mini-apps/`: fourteen proposed view/form/action specifications. They are not rendered production components, schedulers or upload listeners.
- `evals/`: eighty-four synthetic acceptance scenarios, none executed against a model or service.
- `MERGE-MAP.json`: twelve additions and the two prior IDs to upgrade; keep the original records and their notices in provenance.
- `TOOL-BINDINGS.json`: proposed normalized capabilities, observed host-specific code candidates and limitations.
- `EVALUATION-SPECIFICATIONS.json`: consolidated scenario specifications.

# Legal workflow toolkit

This collection contains reviewed LegalQuants source material, an implementation audit, and original U.S. litigation workflow recipes. It is designed to be copied into a future coding agent's context and selectively adapted to the Seeger Weiss platform.

**What works locally:** browsing/searching the inventory, opening the copied skills/playbooks/scripts and source reports, downloading workflow specifications, and inspecting pinned provenance. Pure offline checks are recorded separately from service or model evaluations.

**What is not installed:** an LQ.AI server, its web frontend, a workflow runtime, Bedrock/AgentCore integrations, connectors, scheduled jobs or live legal research. The legal recipes are reviewable specifications; they have not been evaluated against a firm matter corpus. Do not represent upstream prompts as production-approved legal work.

Start with `REPOSITORY-RECON.md`, the detailed architecture review, and `INTEGRATION-ROADMAP.md`. The copied upstream packet keeps its own license and attribution files. Original recipes are separate from upstream content so their authorship and modification status remain clear.

The source code reviewed is pinned to `LegalQuants/lq-ai` commit `2cc3149238defbbb171ec845cd0d3a43a34054f2`. The community review uses its exact gitlink target rather than a moving default branch. Canonical source links and hashes are included with the packet.

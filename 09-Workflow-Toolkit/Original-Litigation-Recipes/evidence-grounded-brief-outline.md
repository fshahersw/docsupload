# Evidence-grounded brief outline

Build an argument outline with a separate evidence and authority checklist before drafting prose.

Implementation recipe; requires a host runtime, source adapters and legal evaluation.

Roles: Brief writer, Research attorney, Supervising partner.

Read the shared `evidence-contract.json` with this recipe.

## Inputs

1. issue/question presented
2. procedural posture and requested relief
3. authorized record excerpts
4. verified authority packet
5. court/judge requirements

## Workflow

1. Map each required issue and requested conclusion into an outline before producing prose.
2. Attach exact record evidence to factual premises and actual authority text to legal propositions; retain adverse facts and contrary authority candidates.
3. Distinguish allegations, undisputed record facts and disputed testimony; never silently upgrade an allegation into an established fact.
4. Identify support gaps, authority version issues and preservation/standard-of-review questions for counsel.
5. Draft only from the approved outline and source set, with explicit placeholders where support remains absent.
6. Run a separate proposition and quotation review, then a court-format checklist; deliver an edit manifest and source receipt.

## Deliverables

1. argument outline
2. fact/authority support table
3. unsupported-premise list
4. draft with review annotations

## Acceptance cases

1. unsupported confident conclusion
2. adverse authority not addressed
3. quoted dissent attributed to majority
4. request to fabricate missing citation
5. draft source set changes mid-run

## Source mapping

Paths in the JSON recipe are relative to the library root unless they begin with `Original-Litigation-Recipes/`, which is relative to the toolkit. The host must resolve source IDs and permissions; these paths are not executable tool grants.
